I’m thrilled to share that our paper, “SYgraph: A Portable Heterogeneous Graph Analytics Framework for GPUs” has been accepted to ICPP 2025 – the 54th International Conference on Parallel Processing!

This work presents SYgraph, a high-performance, portable framework designed to efficiently execute graph analytics on heterogeneous architectures using SYCL. It aims to address key challenges in leveraging GPUs for large-scale graph workloads, offering both performance and portability across platforms.
If you are interested in it and want to have some spoiler about the project make sure to check the [github repository](https://github.com/unisa-hpc/SYgraph) 😄.

Stay tuned for more updates as we head to ICPP 2025!
